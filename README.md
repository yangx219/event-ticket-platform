# Event Ticket Platform

A full-stack event ticketing platform built with Java 21, Spring Boot, PostgreSQL, Keycloak and React.

## Overview

The application allows event organizers to create and manage events, attendees to purchase tickets, and staff to validate tickets using QR codes.

## Tech Stack

- **Backend:** Java 21, Spring Boot, Spring Security, Spring Data JPA
- **Database:** PostgreSQL
- **Authentication:** Keycloak, OAuth 2.0, OpenID Connect, JWT
- **Frontend:** React, TypeScript, Vite
- **Infrastructure:** Docker Compose

## Features

- Event creation and management
- Ticket type configuration
- Event publishing
- Ticket purchasing
- QR code generation and validation
- Role-based access control

## Development Status

This project is currently being tested and extended.

Planned improvements include automated testing, CI/CD, concurrency control and cloud deployment.
